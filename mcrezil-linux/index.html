MCREZIL LINUX

Run a real Linux on your Android 12 or newer phone, built to fit in 20 GB. No rooting, no risk to your Android, and you can remove it any time.

1. Check your phone

Tick each box. If one is not true yet, fix it first so the install goes smoothly.

2. Install two free apps

Termux runs the installer. Get it from F-Droid, not the Play Store, because the Play Store version is outdated and will not work.

A desktop viewer shows your Linux desktop. For Ubuntu and Debian, install “VNC Viewer” by RealVNC from the Play Store. For Kali, install NetHunter KeX from the NetHunter Store. Skip this if you only want the terminal.

Android 12 and 13 tip: Android can close Linux in the background (you see “signal 9”). On Android 14 or newer, turn on Disable child process restrictions in Developer options. On 12 and 13, connect the phone to a computer once and run adb shell "settings put global settings_enable_monitor_phantom_procs false".

3. Pick your Linux

Which Kali tools?

Kali’s full tool collections are too big for a 20 GB phone, so these sets are sized to fit. Use security tools only on systems you own or have written permission to test. Tools that need Wi-Fi monitor mode or packet injection will not work on an unrooted phone.

How will you use it?

4. Run the installer

Open Termux, paste this line, and press Enter. Then follow the prompts and wait for “All done!”

Installer address (host install-linux.sh on your GitHub, then paste its “Raw” link here):

Keep Termux open and the screen on while it works. Desktop installs take 10 to 30 minutes. The installer checks you have enough free space first and sets your background image on the Linux desktop.

5. Start using Linux

Start the desktop by typing this in Termux:

linux-start

Then open your viewer (VNC Viewer, or NetHunter KeX for Kali), connect to localhost:5901, and enter the password you chose. Your Linux desktop appears.

Kali tip: in the installer, choose the full image so the desktop is included. In KeX, set the user to kali and the port to 5901.

To stop it later, type linux-stop.

For a plain terminal at any time, type:

linux-terminal

Want to replace Android completely? That needs an unlocked bootloader and a build made for your exact phone model. Look up your model on postmarketOS or Ubuntu Touch. It can erase your data and void your warranty, so back up first.
